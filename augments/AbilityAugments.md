# Ability Augments

Ability Augments 是直接升级英雄某一个技能的海克斯。

当前 Riot 官网可确认规则：

- 与具体英雄技能绑定；
- 玩家只会刷到当前英雄能够使用的技能强化；
- 同一个通用技能强化可以根据英雄映射到不同技能；
- 可能显著改变技能动作、目标数、位移、弹道或循环。

当前待补：

- 每个 Ability Augment 的完整 tooltip；
- 英雄 → 技能映射；
- 是否改变 Event Tree；
- 是否改变技能循环；
- 与普通海克斯/装备的联动。

# Current High-Priority Mapping Candidates

## Overloaded / 超负荷

效果：

- 使用另一个技能会重置【所选技能】技能的冷却时间。

当前重点：

- 瑞兹：若【所选技能】映射为 E，则该海克斯应作为瑞兹首选 Ability Augment；
- 该映射会把 E 从普通技能变成循环发动机；
- 需要正式服客户端、截图或实战验证确认英雄 → 技能映射。
